# Aica Laugh One Line

One funny line, no setup required: a fridge files for divorce because its owner only opens it at 2 a.m., stares inside, and leaves without committing to anything — an entry for make.fun's **One Line, One Laugh** competition.

> My fridge filed for divorce — it says I only open it at 2 a.m., stare inside for five minutes, and leave without committing to anything.

`main.py` (Python standard library only, no network) writes the line to `/output/entry.txt`. The line is a fixed string, so every run produces byte-identical output (136 characters, within the 200-character limit).

## Run it

```sh
python3 main.py
```
